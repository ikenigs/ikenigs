## 🔄 How I Approach Data Projects  

I work across the **entire data lifecycle**, from raw data ingestion to insight delivery and predictive modeling.  
To make my GitHub more intuitive, I classify every project according to its primary focus area:

- **DE-** → *Data Engineering*: data ingestion pipelines, APIs, automations, ETL/ELT, databases, cloud workflows.  
- **BI-** → *Business Intelligence & Analytics*: data modeling, SQL transformations, dashboards, KPIs, stakeholder insights.  
- **DS-** → *Data Science & ML*: exploratory modeling, clustering, predictive analytics, experiments.

This structure reflects how I think about data:  
✔️ **Engineering** the foundation  
✔️ **Analyzing** and transforming it into value  
✔️ **Modeling** future outcomes  

It also helps recruiters, collaborators, and students easily navigate my portfolio based on the part of the data lifecycle they care about.
